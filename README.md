# CARTÃO DO BAIRRO

PROMPT MESTRE — APP CARTÃO DO BAIRRO

1. VISÃO GERAL DO PROJETO

Desenvolver um aplicativo completo chamado CARTÃO DO BAIRRO, uma plataforma de benefícios que conecta: 
Criar sistema completo com funcionalidade total 
sem erro 

* 👤 Clientes/associados

* 🏪 Empresas parceiras

* 👨‍💼 Administradores

* 💰 Sistema financeiro

* 📍 Localização e navegação

* 🎁 Benefícios e descontos

* 📢 Publicidade e banners

* 📊 Relatórios e indicadores

O aplicativo deve funcionar como uma plataforma centralizada de benefícios locais, permitindo que o cliente encontre empresas parceiras, consulte seus benefícios, apresente seu cartão digital, faça pagamentos pelo próprio aplicativo e encontre empresas próximas através do Google Maps.

O sistema deve ser preparado para crescimento, permitindo futuramente expansão para várias cidades, bairros, regiões e administradores.

4. Enviar notificação.

Controla toda a plataforma. ter aceso total as informações

Todos os módulos devem compartilhar o mesmo banco de dados e respeitar as regras de permissões.

O sistema deve permitir que o Cartão do Bairro cresça de uma operação pequena para uma operação com dezenas, centenas ou milhares de vendedores, parceiros e clientes, mantendo controle de vendas, comissões, pagamentos e desempenho.
